# Декомпозиция эпика: Корзина

## Описание эпика
Реализация функционала корзины для покупки NFT с возможностью просмотра товаров, управления составом корзины, сортировки и имитации оплаты.

---

## Подзадачи

### 1. Модели данных и бизнес-логика

#### 1.1. Создание модели данных для NFT в корзине
- **Описание:** Создать структуру данных для представления NFT в корзине
- **Оценка:** 2 часа
- **Критерии приемки:**
  - Структура содержит: id, изображение, название, рейтинг, цену
  - Соответствует API модели NFT

#### 1.2. Создание модели данных для валюты
- **Описание:** Создать структуру данных для представления валюты оплаты
- **Оценка:** 2 часа
- **Критерии приемки:**
  - Структура содержит: id, логотип, полное название, сокращенное название
  - Соответствует API модели валюты

#### 1.3. Создание сервиса для работы с корзиной (CartService)
- **Описание:** Реализовать сервис для получения, добавления, удаления NFT из корзины
- **Оценка:** 5 часов
- **Критерии приемки:**
  - Методы для получения списка NFT в корзине
  - Метод для удаления NFT из корзины
  - Обработка сетевых ошибок
  - Использование URLSession и GCD

#### 1.4. Создание сервиса для работы с валютами (CurrencyService)
- **Описание:** Реализовать сервис для получения списка валют
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Метод для получения списка доступных валют
  - Обработка сетевых ошибок
  - Использование URLSession и GCD

#### 1.5. Создание сервиса для оплаты (PaymentService)
- **Описание:** Реализовать сервис для имитации оплаты заказа
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Метод для отправки запроса на оплату
  - Обработка успешного ответа
  - Обработка ошибок с возможностью повтора

#### 1.6. Реализация логики сортировки корзины
- **Описание:** Создать утилиту для сортировки NFT в корзине по различным критериям
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Сортировка по названию (по умолчанию)
  - Сортировка по цене
  - Сортировка по рейтингу
  - Сохранение выбранной сортировки в UserDefaults

---

### 2. Экран заказа (CartViewController)

#### 2.1. Создание базовой структуры экрана заказа
- **Описание:** Создать ViewController с UITableView для отображения корзины
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Создан класс CartViewController
  - Настроена UITableView
  - Настроена навигация к экрану

#### 2.2. Создание ячейки для NFT в корзине (CartNFTTableViewCell)
- **Описание:** Реализовать кастомную ячейку таблицы для отображения NFT
- **Оценка:** 5 часов
- **Критерии приемки:**
  - Отображение изображения NFT
  - Отображение названия
  - Отображение рейтинга (звезды или цифры)
  - Отображение цены в ETH
  - Кнопка удаления из корзины
  - Корректная работа с переиспользованием ячеек

#### 2.3. Реализация загрузки и отображения данных корзины
- **Описание:** Интегрировать CartService с экраном, загрузить и отобразить NFT
- **Оценка:** 4 часа
- **Критерии приемки:**
  - Данные загружаются при открытии экрана
  - Отображается индикатор загрузки во время запроса
  - NFT отображаются в таблице после загрузки
  - Обработка пустой корзины

#### 2.4. Реализация нижней панели с итогами
- **Описание:** Создать панель внизу экрана с общей информацией о заказе
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Отображение общего количества NFT
  - Отображение общей суммы в ETH
  - Кнопка оплаты
  - Панель закреплена внизу экрана
  - Корректное обновление при изменении состава корзины

#### 2.5. Реализация кнопки сортировки
- **Описание:** Добавить кнопку сортировки в верхней части экрана
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Кнопка отображается в navigation bar или вверху экрана
  - При нажатии открывается UIAlertController с вариантами сортировки
  - Применение выбранной сортировки обновляет таблицу
  - Сохранение выбранной сортировки в UserDefaults

#### 2.6. Реализация сортировки данных в таблице
- **Описание:** Применить логику сортировки к отображаемым данным
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Данные сортируются согласно выбранному критерию
  - Таблица обновляется после сортировки
  - Восстановление сохраненной сортировки при открытии экрана

#### 2.7. Реализация удаления NFT из корзины
- **Описание:** Добавить функционал удаления NFT по кнопке в ячейке
- **Оценка:** 3 часа
- **Критерии приемки:**
  - При нажатии на кнопку удаления открывается экран подтверждения
  - После подтверждения NFT удаляется из корзины
  - Таблица обновляется после удаления
  - Обновляется нижняя панель с итогами

#### 2.8. Реализация перехода на экран выбора валюты
- **Описание:** Добавить переход на экран оплаты при нажатии на кнопку оплаты
- **Оценка:** 2 часа
- **Критерии приемки:**
  - При нажатии на кнопку оплаты открывается экран выбора валюты
  - Передаются данные о заказе (список NFT, сумма)

#### 3.1. Создание экрана подтверждения удаления
- **Описание:** Создать модальный экран для подтверждения удаления NFT
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Модальное окно с затемненным фоном
  - Отображение изображения NFT
  - Текст подтверждения удаления
  - Кнопка "Удалить"
  - Кнопка "Отмена"

#### 3.2. Реализация логики подтверждения и отмены
- **Описание:** Добавить обработку действий пользователя
- **Оценка:** 2 часа
- **Критерии приемки:**
  - При нажатии "Удалить" NFT удаляется из корзины
  - При нажатии "Отмена" экран закрывается без изменений
  - Закрытие экрана после удаления

### 4. Экран выбора валюты (CurrencySelectionViewController)

#### 4.1. Создание базовой структуры экрана выбора валюты
- **Описание:** Создать ViewController с UICollectionView для отображения валют
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Создан класс CurrencySelectionViewController
  - Настроена UICollectionView
  - Настроена навигация к экрану

#### 4.2. Создание ячейки для валюты (CurrencyCollectionViewCell)
- **Описание:** Реализовать кастомную ячейку коллекции для отображения валюты
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Отображение логотипа валюты
  - Отображение полного названия валюты
  - Отображение сокращенного названия валюты
  - Визуальное выделение выбранной валюты
  - Корректная работа с переиспользованием ячеек

#### 4.3. Реализация загрузки и отображения списка валют
- **Описание:** Интегрировать CurrencyService с экраном, загрузить и отобразить валюты
- **Оценка:** 4 часа
- **Критерии приемки:**
  - Данные загружаются при открытии экрана
  - Отображается индикатор загрузки во время запроса
  - Валюты отображаются в коллекции после загрузки
  - Обработка ошибок загрузки

#### 4.4. Реализация выбора валюты
- **Описание:** Добавить возможность выбора валюты из списка
- **Оценка:** 3 часа
- **Критерии приемки:**
  - При нажатии на ячейку валюта выделяется визуально
  - Можно выбрать только одну валюту
  - Выбранная валюта сохраняется

#### 4.5. Реализация ссылки на пользовательское соглашение
- **Описание:** Добавить ссылку на пользовательское соглашение с открытием в WKWebView
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Ссылка отображается на экране
  - При нажатии открывается WKWebView с документом
  - Возможность вернуться на экран выбора валюты

#### 4.6. Реализация кнопки оплаты
- **Описание:** Добавить кнопку оплаты и обработку нажатия
- **Оценка:** 3 часа
- **Критерии приемки:**
  - Кнопка оплаты отображается на экране
  - Кнопка активна только при выбранной валюте
  - При нажатии отправляется запрос на оплату

#### 4.7. Реализация обработки результата оплаты
- **Описание:** Обработать успешный и неуспешный ответ от сервера
- **Оценка:** 4 часа
- **Критерии приемки:**
  - При успехе отображается экран подтверждения оплаты
  - При ошибке отображается UIAlertController с сообщением об ошибке
  - В UIAlertController кнопки "Повторить" и "Отмена"
  - При "Повторить" запрос отправляется снова
  - При "Отмена" экран закрывается

## Примечания

- Все сетевые запросы должны выполняться с использованием GCD (DispatchQueue)
- UI обновляется только из главного потока
- Настройки сортировки сохраняются в UserDefaults
- По умолчанию сортировка корзины - по названию
- Необходимо обработать все возможные сетевые ошибки
- Все экраны должны иметь индикаторы загрузки
