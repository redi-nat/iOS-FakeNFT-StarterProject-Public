## Технические детали реализации отправки NFT в профиль

### Созданные файлы:
- **ProfileService.swift** - новый сервис для работы с профилем пользователя
  - Протокол `ProfileService` с методом `addPurchasedNFTs(_:completion:)`
  - Реализация `ProfileServiceImpl` с заглушкой (mock-данные)
  - Временное хранилище `purchasedNFTIds: [String]` для тестирования
  - Метод `getPurchasedNFTIds()` для проверки работы заглушки

### Измененные файлы:
- **ServicesAssembly.swift** - добавлен `profileService: ProfileService`
- **CartPresenter.swift** - добавлен метод `getCurrentNFTs() -> [CartNFT]`
- **CartViewController.swift** - модифицирован `payButtonTapped()` для передачи NFT
- **CurrencySelectionAssembly.swift** - обновлен `build()` для приема `purchasedNFTIds`
- **CurrencySelectionPresenter.swift**:
  - Добавлено свойство `profileService: ProfileService`
  - Добавлено свойство `purchasedNFTIds: [String]`
  - Реализован метод `sendNFTsToProfile()` для автоматической отправки после оплаты
- **project.pbxproj** - добавлен ProfileService.swift в проект Xcode

### Поток данных:
1. Пользователь нажимает "Оплатить" в корзине
2. `CartViewController` получает список NFT через `presenter.getCurrentNFTs()`
3. Список ID NFT передается в `CurrencySelectionViewController` при создании
4. После успешной оплаты автоматически вызывается `sendNFTsToProfile()`
5. NFT отправляются в профиль через `ProfileService.addPurchasedNFTs()`
6. Результат логируется в консоль (успех/ошибка)

### Особенности реализации:
- **Заглушка (Mock)**: Реализация использует временное хранилище вместо реального API
- **Асинхронность**: Операция выполняется асинхронно с имитацией задержки сети (0.3 сек)
- **Неблокирующая**: Ошибки при отправке в профиль не блокируют процесс оплаты
- **TODO для интеграции**: В коде есть закомментированный пример реальной реализации через API
