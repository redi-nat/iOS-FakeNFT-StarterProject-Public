# Декомпозиция эпика: Каталог

## Описание эпика
Реализация функционала просмотра коллекций NFT, отображения детальной информации о коллекции и отдельных NFT, а также возможность сортировки и перехода к профилю автора.

---

## Подзадачи

### 1. Модели данных и бизнес-логика

#### 1.1. Создание модели данных для коллекции NFT
- **Описание:** Создать структуру данных для представления коллекции (Collection).
- **Оценка:** 2 часа.
- **Критерии приемки:**
  - Структура содержит: id, название, обложка (cover), массив id NFT, описание, автор.
  - Соответствует API модели коллекции.

#### 1.2. Создание модели данных для NFT
- **Описание:** Создать структуру данных для отдельного NFT.
- **Оценка:** 2 часа.
- **Критерии приемки:**
  - Структура содержит: id, название, изображения, рейтинг, цену, автора.
  - Соответствует API модели NFT.

#### 1.3. Создание сервиса для работы с каталогом (CatalogService)
- **Описание:** Реализовать сервис для получения списка всех коллекций.
- **Оценка:** 4 часа.
- **Критерии приемки:**
  - Метод для получения списка коллекций (GET /collections).
  - Обработка сетевых ошибок и состояний загрузки.
  - Использование URLSession и GCD.

#### 1.4. Реализация логики сортировки каталога
- **Описание:** Создать утилиту для сортировки списка коллекций.
- **Оценка:** 3 часа.
- **Критерии приемки:**
  - Сортировка по названию и по количеству NFT.
  - Сохранение выбранного фильтра в UserDefaults.

---

### 2. Главный экран каталога (CatalogViewController)

#### 2.1. Создание базовой структуры экрана
- **Описание:** Создать ViewController с UITableView для отображения списка коллекций.
- **Оценка:** 4 часа.
- **Критерии приемки:**
  - Настроена UITableView и навигация.
  - Реализован Pull-to-refresh.
  - Интеграция с CatalogService и отображение данных.

#### 2.2. Создание ячейки коллекции (CatalogTableViewCell)
- **Описание:** Реализовать кастомную ячейку таблицы для превью коллекции.
- **Оценка:** 4 часа.
- **Критерии приемки:**
  - Отображение обложки коллекции (Kingfisher).
  - Отображение названия и количества элементов.
  - Корректная работа с переиспользованием.

---

### 3. Экран коллекции (CollectionViewController)

#### 3.1. Создание интерфейса экрана коллекции
- **Описание:** Реализовать экран с обложкой коллекции и сеткой NFT (UICollectionView).
- **Оценка:** 5 часов.
- **Критерии приемки:**
  - Сверху отображается обложка, название, описание и ссылка на автора.
  - Реализована сетка NFT через UICollectionView.

#### 3.2. Создание ячейки NFT (NFTCollectionViewCell)
- **Описание:** Реализовать кастомную ячейку коллекции для NFT.
- **Оценка:** 5 часов.
- **Критерии приемки:**
  - Изображение NFT с кнопкой «Лайк».
  - Отображение рейтинга, названия и цены.
  - Кнопка добавления в корзину.

---
